# Support

- **Start with the docs:** the [README](README.md) covers installing and using the window and the API, and the [docs](docs/README.md) cover architecture, development, testing, releasing and security.
- **Questions and ideas:** use [GitHub Discussions](../../discussions) if enabled, otherwise open an issue.
- **Bugs:** open an issue with the bug report form. Say which part is affected (API or window), your operating system and version, and how you installed it. For the window, also say whether the Microsoft Edge WebView2 runtime is installed.
- **Security problems:** see [SECURITY.md](SECURITY.md).
