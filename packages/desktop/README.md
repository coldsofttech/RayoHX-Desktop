# rayohx-desktop

The RayoHX desktop window for Windows: the `rayohxd` command, a React front end in a native window
with the HTTP API built in. It is released as a compiled wheel for Windows on GitHub, not on PyPI,
and needs Python 3.15 or newer.

See the [RayoHX Desktop README](https://github.com/coldsofttech/RayoHX-Desktop#readme) for what it does
and how to install it, and the [window guide](https://github.com/coldsofttech/RayoHX-Desktop/blob/main/docs/guides/ui.md)
for using it.

Apache-2.0.
