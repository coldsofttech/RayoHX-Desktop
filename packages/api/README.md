# rayohx-api

The internal HTTP API of RayoHX Desktop, mounted inside the desktop window. It is not a separate
program and is not published on PyPI; users install RayoHX Desktop (the Windows setup or the portable
zip) from GitHub.

See the [API guide](https://github.com/coldsofttech/RayoHX-Desktop/blob/main/docs/api.md) for the
settings and endpoints, and the [RayoHX Desktop README](https://github.com/coldsofttech/RayoHX-Desktop#readme)
for how to install it.

Apache-2.0.
