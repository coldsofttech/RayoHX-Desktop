# rayohx-api

The RayoHX HTTP API for working with HLS streams: the `rayohx-api` command, also mounted inside the
desktop window. It is released as a compiled wheel for Windows on GitHub, not on PyPI, and needs
Python 3.15 or newer.

See the [API guide](https://github.com/coldsofttech/RayoHX-Desktop/blob/main/docs/api.md) for the
settings and endpoints, and the [RayoHX Desktop README](https://github.com/coldsofttech/RayoHX-Desktop#readme)
for how to install it.

Apache-2.0.
