# Documentation

Technical documentation for this project lives in this folder. The top-level [README](../README.md) is for users.

- [API guide](api.md): running the API, its settings, the endpoints and authentication; the [OpenAPI contract](openapi.json) is generated from the app.
- [Architecture](architecture.md): how the repository fits together, and how the API and the window are built.
- [Development](development.md): set-up, running, checks, adding to the API and the front end, and the compiled builds.
- [Testing](testing.md): how tests are organized and the shared `rayohx-pytest` plugin.
- [Packaging and releasing](packaging.md): what the compiled wheels hold, how to build and install them, and how a release is made and attached to GitHub.
- [Security](security.md): how the API and the window protect requests and data.
- [Window guide](guides/ui.md): adding streams, downloads and settings in the window.
